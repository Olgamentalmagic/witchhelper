ЧТО УЖЕ ЛЕЖИТ В РЕПОЗИТОРИИ
===========================
Папка docs/ — это и есть сайт.

  docs/index.html     ← ГЛАВНАЯ СТРАНИЦА (имя файла обязательно index.html)
  docs/styles.css     ← оформление
  docs/assets/        ← иконка, скрины, видео

Браузер на GitHub Pages всегда открывает файл с именем index.html.
Другое имя (типа page.html) для главной НЕ нужно.


ШАГ 1. ЗАЛИТЬ НА GITHUB
=======================
1) Открой репозиторий приложения на github.com
   (тот же, где лежит код Помощника Ведьмы — или создай новый репозиторий
   только под лендинг, если так удобнее).

2) Залей папку docs целиком:
   - либо через git push (commit → push),
   - либо через сайт GitHub: Add file → Upload files → перетащи всю папку docs.

Важно: на GitHub должна появиться папка docs с файлом index.html внутри.


ШАГ 2. ВКЛЮЧИТЬ GITHUB PAGES
============================
1) На странице репозитория нажми Settings (Настройки).
2) В левом меню найди Pages.
3) Block "Build and deployment":
   - Source: Deploy from a branch
   - Branch: main  (или master — какая у тебя основная)
   - Folder: /docs   ← вот это важно, не "/" и не "/root"
4) Нажми Save.

Через 1–3 минуты сверху на той же странице Pages появится адрес вида:

  https://ТВОЙ_НИК.github.io/ИМЯ_РЕПОЗИТОРИЯ/

Именно эту ссылку вставляешь в рекламу Facebook как «сайт».


ШАГ 3. ПРОВЕРКА
===============
Открой ссылку в браузере (лучше с телефона).
Должны быть: текст, скрины, видео, кнопка «Открыть в Google Play».
Кнопка ведёт на:
  https://play.google.com/store/apps/details?id=ru.witchhelper.app


ЕСЛИ СТРАНИЦА 404
=================
- Подожди ещё пару минут после Save.
- Проверь, что branch = main/master и folder = /docs.
- Проверь, что файл называется именно index.html (маленькими буквами).


ДЛЯ РЕКЛАМЫ В FACEBOOK
======================
Цель кампании: Трафик → сайт.
URL: твоя ссылка github.io (не прямая на Play в объявлении, если льёшь на сайт).
На странице Play-ссылка видна всем — это нормальный лендинг приложения, не клоака.
